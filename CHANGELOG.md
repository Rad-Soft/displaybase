# Changelog

## 0.1.0

The first release.

- Hand any number of screens to another computer and bring them back
- Screens that always go, sometimes go, or stay
- Turns a screen off in macOS while it's away, and puts layout, rotation and windows back
- Follows a USB switch
- Optional checks over SSH, for Windows, Linux and macOS
- Guided setup, a shortcut you can change, and `displaybase://` links
- Signed updates
