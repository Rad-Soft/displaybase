# Code of conduct

This project follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good faith, and keep it about the work. Harassment, insults and publishing someone's private information aren't welcome here.

It applies in this repository and anywhere someone is speaking for the project. Report a problem to hello@radsoftinc.com. Reports are kept private, and maintainers can remove comments or block people who break these rules.
